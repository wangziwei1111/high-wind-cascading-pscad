# PSCAD Workspace Area

This directory contains clean-rebuild instructions only. Restricted PSCAD projects, libraries, generated build outputs, and third-party model sources must not be committed here.

Use:

- `dirty_reference/` to document the frozen dirty-but-working reference.
- `clean_model/` to document the target clean IEEE39 model.
- `interface_shell/` to document the minimal PSCAD-MATLAB shell.
- `migration_checklists/` to guide manual PSCAD GUI work.
